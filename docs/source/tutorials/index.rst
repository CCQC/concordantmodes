Tutorials
=========

Each tutorial follows one of the examples in the ``examples`` directory of the
repository. Copy the example's files into a new directory and follow along.
The quantum chemistry calculations themselves are not part of the tutorials:
run them with your own Molpro or Psi4 installation, or let CMA submit them
(:doc:`../user_guide/running`).
