Options reference
=================

Options are set in ``cma.toml`` (``name = value``, TOML syntax) or as keyword
arguments to ``Options(...)`` in a ``main.py``. Unknown names and invalid
values are reported before anything runs. ``cma options [name]`` prints this
list in the terminal.


Input and geometry
------------------

``cart_coords``
    Default: ``'Bohr'``. Units of the Cartesian geometry in the zmat file.

``cart_insert_a``
    Default: ``-1``. Line number in templateA.dat after which the geometry is inserted. Leave at -1 and put a {geometry} line in the template instead.

``cart_insert_b``
    Default: ``-1``. Same as cart_insert_a, for templateB.dat.

``cart_insert_c``
    Default: ``-1``. Same as cart_insert_a, for templateC.dat (CMA-2, experimental).

``geom_check``
    Default: ``False``. Read the zmat file, report the structure and coordinates, and stop.


Internal coordinates
--------------------

``coords``
    Default: ``'ZMAT'``. Internal coordinate system: 'ZMAT' (from the Z-matrix), 'Custom' (the coordinates listed in the zmat file) or 'Delocalized' (all bonds/angles/torsions, made non-redundant).

``covalent_radii``
    Default: ``False``. Find bonds automatically from covalent radii instead of the zmat connectivity.

``bond_threshold``
    Default: ``1.2``. With covalent_radii, atoms closer than bond_threshold x (sum of covalent radii) are bonded.

``topo_analysis``
    Default: ``False``. With Delocalized coordinates, run the ring/topology analysis on the bond graph.

``topo_max_it``
    Default: ``20``. Longest bond walk (ring size) considered by topo_analysis.

``man_proj``
    Default: ``False``. Use a projection matrix you supply (ConcordantModes(options, proj=...)) instead of building one.

``red_tol``
    Default: ``0.0001``. Singular values of the B-matrix below this are treated as redundant coordinates.


Levels of theory and output parsing
-----------------------------------

``program_a``
    Default: ``'molpro'``. Program for the high-level (A) single points: molpro, psi4, orca or cfour (an '@version' suffix is allowed).

``program_b``
    Default: ``'molpro'``. Program for the low-level (B) calculations.

``program_c``
    Default: ``'molpro'``. Program for level C (CMA-2, experimental).

``method_a``
    Default: ``''``. Method whose energy is read from level-A outputs, e.g. 'ccsd(t)'. Only needed for Molpro inputs that run several methods; empty uses the program's final energy.

``method_b``
    Default: ``''``. Same as method_a, for level B.

``method_c``
    Default: ``''``. Same as method_a, for level C.

``energy_regex_a``
    Default: ``''``. Regular expression with one group capturing the level-A energy. Empty uses the built-in preset for program_a/method_a.

``energy_regex_b``
    Default: ``''``. Same as energy_regex_a, for level B.

``energy_regex_c``
    Default: ``''``. Same as energy_regex_a, for level C.

``success_regex_a``
    Default: ``''``. Regular expression that must appear in a finished level-A output. Empty uses the program's normal-termination line.

``success_regex_b``
    Default: ``''``. Same as success_regex_a, for level B.

``success_regex_c``
    Default: ``''``. Same as success_regex_a, for level C.

``gradient_regex_a``
    Default: ``''``. [start, end] regular expressions bracketing the gradient block (deriv_level_a = 1). Empty uses the program preset.

``gradient_regex_b``
    Default: ``''``. Same as gradient_regex_a, for level B.

``gradient_regex_c``
    Default: ``''``. Same as gradient_regex_a, for level C.


Displacements and force constants
---------------------------------

``deriv_level_a``
    Default: ``0``. 0: level-A force constants from energies; 1: from gradients.

``deriv_level_b``
    Default: ``0``. 0: level-B force constants from energies; 1: from gradients.

``deriv_level_c``
    Default: ``0``. Same as deriv_level_a, for level C.

``disp_a``
    Default: ``0.01``. Displacement size for level A (normal-coordinate units).

``disp_b``
    Default: ``0.01``. Displacement size for level B (internal-coordinate units).

``disp_c``
    Default: ``0.01``. Displacement size for level C.

``off_diag``
    Default: ``0``. Off-diagonal level-A force constants: 0 = diagonal only (CMA-0); 2 = CMA-2 couplings chosen by xi_tol (experimental).

``xi_tol``
    Default: ``0.02``. CMA-2: couple modes i,j when \|F_ij\|/sqrt(\|F_ii F_jj\|) exceeds this.

``de_novo_C``
    Default: ``False``. CMA-2: compute level C from new calculations instead of reusing level-B outputs.

``reduced_disp``
    Default: ``False``. Scale level-A displacements by the level-B force constants.

``reduced_disp_size``
    Default: ``0.0025``. Target energy change used by reduced_disp.

``scaled_disp``
    Default: ``False``. Scale level-B displacements (see transf_disp).

``tight_disp``
    Default: ``False``. Converge the internal-to-Cartesian back-transformation more tightly.

``transf_max_it``
    Default: ``50``. Maximum iterations of the internal-to-Cartesian back-transformation.

``transf_tol``
    Default: ``1e-07``. Convergence threshold of the back-transformation.

``second_order``
    Default: ``False``. Include second-order (B2) terms when converting force constants; needed away from stationary points.

``cart_fc_b``
    Default: ``False``. Compute the level-B Hessian in Cartesian instead of internal coordinates.

``conv_grad``
    Default: ``True``. Convert Cartesian gradients to internal coordinates when reading them.


Running the calculations
------------------------

``cluster``
    Default: ``'manual'``. 'manual': CMA writes the inputs and you run them, then rerun CMA. 'slurm' or 'sge': CMA submits, waits and continues. 'custom': CMA runs custom_submit_str in each displacement directory.

``cluster_profile``
    Default: ``''``. Named group of cluster settings applied before your own options, e.g. 'sapelo2_hfslab'. See the profiles section of the docs.

``job_template``
    Default: ``''``. Path to your own job script. Placeholders such as {nslots}, {memory}, {time_limit}, {queue}, {job_name}, {run_command}, {job_setup} and {directives} are filled in.

``job_name``
    Default: ``'Concordant'``. Scheduler job name.

``queue``
    Default: ``'batch'``. Slurm partition or SGE queue.

``nslots``
    Default: ``1``. CPU cores per displacement calculation ($NSLOTS in the job script).

``memory``
    Default: ``'32GB'``. Memory per displacement job, in scheduler syntax (e.g. '32GB').

``time_limit``
    Default: ``'04:00:00'``. Wall-time limit per displacement job.

``scheduler_directives``
    Default: ``[]``. Extra scheduler lines added to the job script, e.g. ['#SBATCH --constraint=EPYC'].

``job_setup``
    Default: ``''``. Shell lines run before the program in each job (module load, conda activate, scratch setup...).

``run_command_a``
    Default: ``''``. Command that runs one level-A calculation in its directory. Empty uses the program's default command.

``run_command_b``
    Default: ``''``. Same as run_command_a, for level B.

``run_command_c``
    Default: ``''``. Same as run_command_a, for level C.

``custom_submit_str``
    Default: ``''``. With cluster='custom': command run in each displacement directory, followed by the path of sub_script.sh.

``poll_interval``
    Default: ``30``. Seconds between scheduler status checks.

``slurm_array``
    Default: ``True``. Slurm: submit displacements as job arrays (False: one job per displacement).

``max_array_size``
    Default: ``5000``. Largest job array to submit; bigger runs are split. Match your cluster's MaxArraySize.

``array_throttle``
    Default: ``None``. Maximum array tasks running at once (Slurm '%N'); None for no limit.


Symmetry
--------

``molsym_symmetry``
    Default: ``False``. Use MolSym to build symmetry-adapted coordinates and skip symmetry-equivalent displacements.

``subgroup``
    Default: ``False``. With molsym_symmetry, work in this point subgroup (e.g. 'C2v').

``exploit_degen``
    Default: ``True``. Use degeneracies to skip partner-function displacements.

``partner_functions``
    Default: ``True``. Keep both partner functions of degenerate irreps.

``exploit_pm_symm``
    Default: ``False``. Skip minus displacements that are symmetry-equivalent to plus displacements.

``only_TSIR``
    Default: ``False``. Only displace along totally symmetric coordinates.


Output and analysis
-------------------

``verbosity``
    Default: ``'normal'``. 'quiet' (warnings only), 'normal' (progress and results) or 'debug' (all intermediate output).

``log_file``
    Default: ``'cma.log'``. File receiving the full debug-level log of each run; '' to disable.

``write_molden``
    Default: ``True``. Write the final normal modes to a MOLDEN file. When the level-A force constants are read from force_constants/fc_int_a.dat, the level-A displacements are rebuilt in memory for it (DispsA is not read).

``ted_check``
    Default: ``False``. Print the total energy distribution of the level-B modes.

``units``
    Default: ``'HartreeBohr'``. Units of the written force constants: 'HartreeBohr' or 'MdyneAng'.


Advanced
--------

``tol``
    Default: ``1e-14``. Matrix elements smaller than this are set to zero.
